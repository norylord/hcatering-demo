# hCatering · демоверсия

Статический интерактивный прототип для просмотра на GitHub Pages. Файлы сайта находятся в `docs/`. GitHub Pages публикует эту папку из ветки `main`.

## Посмотреть

Откройте витрину, добавьте блюдо в корзину и оформите тестовую заявку. По ссылке «Демоадминка» можно увидеть её во вкладке «Заявки», поменять цены, загрузить фото и отредактировать рецептуры. Форма конструктора сохраняет результат во вкладке «Обращения». Обновите витрину, чтобы увидеть правки.

Все изменения хранятся в этом браузере. В формах используются вымышленные контакты. У каждого посетителя своя копия меню. Оформление заявки демонстрирует работу интерфейса.

## Публикация

Требуются Git и авторизованный GitHub CLI. Выполните `./publish.sh` из локального клона. При первом запуске скрипт создаёт публичный репозиторий hcatering-demo в текущем аккаунте GitHub. Затем отправляет main, включает Pages для /docs и выводит адрес после сборки.

## Локальный просмотр

Запустите `python3 -m http.server 8080 --directory docs` и откройте http://localhost:8080/.
